# Open House Chicago

Maps and analysis about [Open House Chicago](https://www.openhousechicago.org), the Chicago Architecture Center's annual weekend of free access to buildings across the city.

| Project | What it is |
|---|---|
| [coffee-walks](coffee-walks/) | Walking routes from the sites new to Open House Chicago 2026 to the nearest South Side coffee shop |

Each project is a static page; GitHub Pages serves it at `https://stevevance.github.io/openhousechicago/<project>/`.
